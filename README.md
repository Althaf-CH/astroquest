# 🚀 ASTROQUEST — Junior Astronaut Mission Trainer

**Explore space. Make critical decisions. Complete your mission.**

ASTROQUEST is an interactive space survival game that introduces players to the challenges of managing an astronaut mission. Players make mission decisions, manage essential resources, respond to emergencies, and try to bring their crew safely through their space expedition.

## 🌌 About the Project

Space exploration requires careful planning, teamwork, resource management, and quick decision-making.

ASTROQUEST turns these ideas into an interactive browser game where players experience the responsibilities of a junior astronaut and learn how decisions can affect a mission.

## ✨ Features

* 🌍 **Mission Destinations:** Choose between Moon and Mars missions.
* 🎮 **Interactive Gameplay:** Make decisions that influence mission outcomes.
* 🫁 **Resource Management:** Monitor oxygen, water, food, energy, and crew health.
* 🚨 **Emergency Scenarios:** Respond to unexpected mission challenges.
* 🎚️ **Difficulty Levels:** Choose Easy, Normal, or Hard.
* 🏆 **Achievements:** Unlock badges by completing gameplay milestones.
* 📊 **Flight Records:** Track personal scores and mission achievements.
* 🔊 **Sound Effects:** Toggle game audio on or off.
* 📋 **Mission Reports:** Review your performance at the end of a mission.
* 💾 **Local Progress:** Save supported game records in your browser.
* 📱 **Responsive Interface:** Play on supported desktop and mobile browsers.

## 🛠️ Built With

## 🎯 Objective

Complete your space mission by managing resources wisely, responding to emergencies, protecting the crew, and making strategic decisions.

Every decision matters. Can you become a successful astronaut?

## ▶️ Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/astroquest.git
   ```

2. Open the project folder in Visual Studio Code.

3. Open `index.html` in your browser, or use the Live Server extension in VS Code.

No package installation or build process is required for the current HTML, CSS, and JavaScript version.

## 💾 Progress and Data

The game uses browser storage for supported local records, such as scores, achievements, and sound preferences.

These records are stored in the player's browser. They are not automatically shared between different devices or browsers.
